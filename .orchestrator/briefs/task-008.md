## Brief
Make the ISO ship the new Python installer instead of the old whiptail script.

Context: repo is /home/gentoobdw/wheatley-linux. The new installer lives in packages/wheatley-installer/ as a pure-stdlib Python package (`python -m wheatley_installer --dry-run` works, 351 tests pass). packages/wheatley-installer/PKGBUILD currently installs only the legacy bash script `wheatley-install` (whiptail/libnewt) plus `pacman.conf` → /usr/share/wheatley/pacman.conf (pacman.conf is staged next to the PKGBUILD by scripts/make-iso.sh; keep that mechanism and that installed path EXACTLY). The ISO profile pulls the `wheatley-installer` package and auto-runs `sudo wheatley-install` on the live TTY — so the binary name must remain `wheatley-install`.

Do four things:

1) REWRITE packages/wheatley-installer/PKGBUILD: bump pkgrel; pkgdesc mentions the Python TUI installer; depends = python (>=3.10), artools-base (provides fstabgen/basestrap tooling used on the live ISO), gptfdisk, dosfstools, e2fsprogs, grub, efibootmgr, util-linux (lsblk) — drop libnewt and bash-as-installer deps. source: keep 'pacman.conf' (SKIP) and reference the module tree; simplest robust approach: in package(), copy the repo-adjacent `wheatley_installer/` package dir and `catalog/` dir from $startdir (they sit next to the PKGBUILD; using $startdir copies is acceptable for this personal repo-local package — mirror how the old PKGBUILD relied on staged files). Install layout: module → /usr/lib/wheatley-installer/wheatley_installer/ (all .py files, no tests, no __pycache__); catalog + screenshots → /usr/share/wheatley-installer/catalog/catalog.json and /usr/share/wheatley-installer/catalog/screenshots/; keep pacman.conf → /usr/share/wheatley/pacman.conf; launcher → /usr/bin/wheatley-install (mode 755).

2) REPLACE the 584-line bash script packages/wheatley-installer/wheatley-install with a ~5-line POSIX sh launcher: exec python3 with PYTHONPATH=/usr/lib/wheatley-installer running `python3 -m wheatley_installer "$@"` (e.g. `exec env PYTHONPATH=/usr/lib/wheatley-installer${PYTHONPATH:+:$PYTHONPATH} python3 -m wheatley_installer "$@"`).
